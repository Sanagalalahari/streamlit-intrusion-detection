# 🚨 Network Intrusion Detection System (CICIDS 2017)

An interactive **Machine Learning-based Intrusion Detection System** built using the **CICIDS 2017 dataset**. This project detects anomalous network traffic and visualizes results through a **Streamlit dashboard**.

---

## 📌 Overview

With the increasing number of cyber threats, detecting malicious network activity is critical. This project focuses on building an **anomaly detection model** that classifies network traffic as **normal or malicious** using machine learning techniques.

The system is deployed using **Streamlit**, providing a simple and interactive interface to analyze predictions and model performance.

---

## 🚀 Features

- 🔍 Detects anomalous network traffic (Intrusion Detection)
- 🤖 Machine Learning-based classification
- 📊 Interactive dashboard using Streamlit
- 📈 Visualization of predictions and performance metrics
- ⚡ Real-time user interaction

---

## 🧠 Tech Stack

- **Programming Language:** Python  
- **Libraries:** Pandas, NumPy, Scikit-learn  
- **Visualization:** Matplotlib / Seaborn

## ▶️ How to Run

1. Clone the repository:

2. Navigate to the project folder:
cd streamlit-intrusion-detection

3. Install required dependencies:
pip install -r requirements.txt

4. Run the Streamlit app:
streamlit run app.py
